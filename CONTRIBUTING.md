# Contributing

Thanks for helping improve HetznerWatch.

1. Open an issue for significant changes so the approach can be discussed.
2. Keep changes focused and do not commit tokens, databases or `.env` files.
3. Run `python -m unittest -v` before submitting a pull request.
4. Describe the user-visible change and any migration considerations in the
   pull request.
